# F-14-C: Flagged Review Moderation

**Epic:** [[EPIC-14-Admin-Panel|EPIC-14: Admin Panel]]
**Status:** ✅ Done

---

## Overview
This is the core use case that triggered EPIC-14. When a business owner flags a review, an admin must review it and either:
- **Approve the flag** → remove the review from the public page
- **Dismiss the flag** → clear the flag, review stays visible
